Settings profiles

About settings profiles

Settings profiles (technical: configuration profiles / policies) let you send a group of settings to managed devices. For example, a profile might require a password, set screen lock timing, or configure security options.

How it works
  • You create a profile and choose which devices or groups receive it.
  • Devices apply settings when they next contact the server.
  • If settings conflict, the device may report that it could not apply them.
Example: Drive encryption (BitLocker) If you enable drive encryption settings, Windows can encrypt data on the device drive. Make sure recovery key handling is configured and documented before applying encryption broadly. Technical: BitLocker-related settings require supported Windows editions and proper key escrow/recovery planning.
